## Interactive DH Robot Visualizer

A web application for exploring robot forward kinematics using Denavit–Hartenberg parameters and interactive joint controls. Developed collaboratively using Python, Dash, Plotly and NumPy.

### Engineering Highlights

- Displays joint frames and axis orientations for a three-link manipulator
- Supports revolute and prismatic joint motion using DH parameters
- Provides continuous parameter sliders, exact numeric inputs and an end-effector transform
- Implements automated analytical reference tests for key transforms
- Includes deployment configuration for Render
